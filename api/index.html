Search for Merchant Defaults via API

Check whether a funded business has a default on record in FinDex, from your own systems. Same matching and privacy as a search in the portal.

Access

API access is available to approved FinDex companies on request. Each key is shown once when it is created. Keep it on your server, never in a browser or app.

Request

Send the EIN, or the business’s legal name and state of registration.

POST https://app.joinfindex.com/api/v1/defaults
Authorization: Bearer fdx_your_key
Content-Type: application/json

{ "ein": "12-3456789" }

Or by legal name and state:

{ "name": "Joe's Cafe LLC", "state": "TX" }

Names are matched exactly, ignoring case, punctuation, and endings like LLC or Inc. An EIN match is the most reliable.

Response

{
  "search_id": "3f1c…",
  "searched_by": "ein",
  "has_default": true,
  "defaults": [
    {
      "incident_date": "2026-09-15",
      "published_on": "2026-10-01",
      "reported_by": "Acme Funding LLC"
    }
  ],
  "other_reports": 0,
  "recent_searches": { "days": 30, "companies": 2, "searches": 3 },
  "results_url": "https://app.joinfindex.com/search/results/3f1c…"
}
has_default
True when at least one published default is on record.
defaults
Each published default: when it happened, when it was published, and the company that reported it.
other_reports
Published reports of other kinds, such as document manipulation. Open results_url to read them.
recent_searches
Searches of this business by other companies in the last 30 days.
results_url
The full results in the portal for 7 days, when signed in to your company’s account.

Only published reports are returned. Reports in their 10-day notice period or under dispute are not included.

Errors

401 invalid_key
Missing, invalid, or revoked key.
422 invalid_request
The EIN, name, or state is missing or invalid. The message says which.
429 rate_limited
More than 300 lookups in an hour for this key.

Records and privacy

Every lookup is logged as a search by your company and appears in your search history. FinDex never stores the EIN you send, only a one-way key used for matching and for counting recent searches. Use the results only for underwriting decisions, under the member terms you accepted.
