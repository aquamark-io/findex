Funded Business API

Check funded businesses for defaults, document tampering, or both, from your own systems. Same matching and privacy as a search in the portal.

Three checks

CheckSend
Defaults only"checks": ["default"]
Document tampering only"checks": ["document_tampering"]
Both"checks": ["default", "document_tampering"], or leave checks out

Access

Approved FinDex companies can request API access from their dashboard. Once your request is approved, you create and revoke your own keys there. Each key is shown once when it is created. Keep it on your server, never in a browser or app.

Request

Send the EIN, or the business’s legal name and state of registration, with the checks you want.

POST https://app.joinfindex.com/api/v1/funded-business
Authorization: Bearer fdx_your_key
Content-Type: application/json

{
  "ein": "12-3456789",
  "checks": ["default", "document_tampering"]
}

Or by legal name and state, defaults only:

{ "name": "Joe's Cafe LLC", "state": "TX", "checks": ["default"] }

Names are matched exactly, ignoring case, punctuation, and endings like LLC or Inc. An EIN match is the most reliable.

Response

{
  "search_id": "3f1c…",
  "searched_by": "ein",
  "checks": {
    "default": {
      "on_record": true,
      "reports": [
        {
          "incident_date": "2026-09-15",
          "published_on": "2026-10-01",
          "reported_by": "Acme Funding LLC"
        }
      ]
    },
    "document_tampering": {
      "on_record": false,
      "reports": []
    }
  },
  "recent_searches": { "days": 30, "companies": 2, "searches": 3 },
  "results_url": "https://app.joinfindex.com/search/results/3f1c…"
}
checks
One entry for each check you asked for.
on_record
True when at least one published report of that type is on record.
reports
Each published report: when it happened, when it was published, and the company that reported it.
recent_searches
Searches of this business by other companies in the last 30 days. A count only, never which companies.
results_url
The full results in the portal for 7 days, including each report’s description and evidence, when signed in to your company’s account.

Only published reports are returned. Reports in their 10-day notice period or under dispute are not included.

Errors

401 invalid_key
Missing, invalid, or revoked key.
422 invalid_request
The EIN, name, state, or checks are missing or invalid. The message says which.
429 rate_limited
More than 300 lookups in an hour for this key.

Records and privacy

Every lookup is logged as a search by your company and appears in your search history. FinDex never stores the EIN you send, only a one-way key used for matching and for counting recent searches. Use the results only for underwriting decisions, under the member terms you accepted.
