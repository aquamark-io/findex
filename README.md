# findex-site

Public site for FinDex (joinfindex.com). Static HTML/CSS, deployed by Vercel from `main`.

## Current state

Coming-soon landing page. Apply, sign-in and subject actions (respond, request record, dispute) are shown as disabled until the portal launches.

## Files

- `index.html`: landing page
- `styles.css`: site styles
- `brands.js`: Our Brands section config (order, URLs, logo paths)
- `logos/`: approved brand logos (to be added)

## Our Brands

Edit `brands.js` to add logo paths. Order stays Aquamark, Secure Broker, Secure Funder, FinDex.
